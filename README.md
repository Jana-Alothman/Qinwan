# Qinwan

## Short Description
Qinwan is a web-based agricultural investment platform that connects investors with date palm farm owners. The platform allows investors to browse farms, submit investment requests, track their investments, and receive updates, while farmers can manage their farms and investment requests through a dedicated dashboard.

## Features
- Browse available farms
- Filter farms by region and size
- Add farms to wishlist
- Submit investment requests
- Track investment status
- Farmers can manage farm details and investment requests
- Farmers can post periodic investment updates
- Investors can rate and review farms
- Admin can manage farms, users, and platform content

## Pages Description

**index.html**  
The homepage that provides an overview of the platform and allows users to navigate to main sections.

**farms.html**  
Displays a list of available farms. Users can browse farms and apply filters.

**farm-details.html**  
Shows detailed information about a specific farm including location, palm type, available area, and investment opportunities.

**wishlist.html**  
Allows investors to save farms they are interested in.

**investment.html**  
Allows investors to submit investment requests and select investment options.

**dashboard.html**  
Displays the investor dashboard where users can track their investments and view updates from farmers.

**farmer-dashboard.html**  
Allows farmers to manage their farms, review investment requests, and post updates.

**login.html**  
Handles user authentication and login.

**signup.html**  
Allows new users to create accounts.

**admin.html**  
Allows the administrator to manage farms, users, and platform activity.
